Cách chạy trong VS Code không bị lỗi

Chọn 1 trong 3 cách siêu đơn giản sau:

1 Cách dễ nhất: Click đúp vào file HTML (0 cài đặt)

Bạn chỉ cần mở thư mục trong VS Code, nhấp chuột phải vào file app.html chọn Open with Live Server hoặc mở trực tiếp trên Chrome/Edge. Giao diện chạy mượt mà ngay lập tức!

2 Bằng Terminal Python có sẵn (Không cần cài pip gì cả!)

Mở Terminal trong VS Code và gõ: 

python server.py

File server.py dùng thư viện có sẵn của Python, tự động mở trình duyệt lên cho bạn mà không bao giờ báo lỗi thiếu package!

3 Bằng Node.js / Vite 
npm install
npm run dev
